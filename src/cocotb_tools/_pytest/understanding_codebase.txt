WHAT HAPPENS IN LOGGING.PY?
-essentially customizing Python's logging system to make it simulation-aware.

While Python knows things like:
- What message was logged.
- Which logger generated it.
- Whether it's INFO, WARNING, ERROR, etc.
Python doesn't inherently know the current hardware simulation time....Cocotb does.

This code bridges the gap between Python's logging system and Cocotb's simulation-time system.


ARCHITECTURE
System 1
Python Logging

Generates log messages and creates LogRecord objects.


System 2
Cocotb Simulation Time

Knows the current simulation time and its reporting precision.



System 3
pytest Logging Plugin

Handles where logs go: terminal, files, captured logs and test reports.

Workflow of the code
1. A Cocotb test generates a log message.
2. Python's logging system creates a LogRecord object containing the logging information.
3. Cocotb's custom LogRecordFactory intercepts the record creation process.
4. SimContextFilter retrieves the current simulation time using Cocotb's simulation-time API.
5. The filter attaches three attributes to the log record:
   - sim_time – Numeric simulation time.
   - sim_time_str – Formatted simulation time.
   - sim_time_unit – Simulation time unit (ns, ps, etc.).
6. The enriched log record is passed to the logging handlers.
7. pytest's logging handlers process the record.
8. The custom log format displays simulation time along with the log level, logger name and message.






Role of the code components understood so far
- Imports: Bring in Python logging, Cocotb simulation-time functionality and pytest logging components.

- COCOTB_LOG_FORMAT: Defines how log messages should be displayed, including simulation time, time unit, logging level, logger name and message.

- get_level(): Converts logging-level names such as DEBUG, INFO and ERROR into their corresponding integer values required by Python's logging system.

- SimContextFilter: Custom logging filter responsible for attaching simulation-time information to log records.

- SimContextFilter.__init__(): Checks whether Cocotb is running in simulation mode and stores that information.

- SimContextFilter.filter(): Checks whether simulation-time information already exists, retrieves it if necessary, attaches the time and unit, and allows the log record to continue.
